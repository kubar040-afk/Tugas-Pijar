# 🏍️ Pengingat Servis App

**Asisten Digital Perawatan Motor Anda**

Aplikasi web sederhana namun powerful untuk membantu Anda mengelola jadwal servis motor dengan cerdas berdasarkan jenis kendaraan, pola penggunaan, dan jarak tempuh.

## ✨ Fitur Utama

- 🚗 **3 Jenis Kendaraan**: Motor Matic, Motor Bebek, Motor Sport
- 📊 **4 Kategori Pemakaian**: Menganggur, Normal, Berat, Sangat Berat
- 📅 **Sistem Dual-Check**: Berdasarkan waktu (hari) dan jarak tempuh (KM)
- 🔧 **Checklist Komponen**: Analisis otomatis 20+ komponen motor
- 📱 **Responsive Design**: Bekerja sempurna di desktop, tablet, dan mobile
- 🎨 **UI Modern**: Desain gradient dengan animasi smooth

## 🚀 Cara Menggunakan

1. **Pilih Jenis Kendaraan**: Matic, Bebek, atau Sport
2. **Pilih Kategori Pemakaian**: Sesuaikan dengan aktivitas harian Anda
3. **Input Tanggal Servis Terakhir**: Kapan terakhir motor Anda diservis
4. **Input KM Terakhir**: Kilometernya saat servis terakhir
5. **Input KM Sekarang** (opsional): Biarkan kosong untuk estimasi otomatis
6. **Klik "Cek Status Servis"**: Lihat hasil analisis

## 📋 Komponen yang Dimonitor

### Untuk Motor Menganggur:
- Aki (60 hari)
- Bensin (60 hari)
- Oli Mesin (90 hari)
- Busi (365 hari)
- Ban Motor (365 hari)
- Minyak Rem (730 hari)
- Dan komponen khusus lainnya per jenis motor

### Untuk Motor Aktif:
- Oli Mesin (2000 KM)
- Filter Udara (12000 KM)
- Busi (8000-10000 KM)
- Rantai (500-1000 KM)
- Dan komponen pemeliharaan rutin lainnya
